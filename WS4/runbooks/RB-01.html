Error codes of the billing application

X7Q-4421

Meaning: the billing service could not open a database connection because pgbouncer refused it. The pgbouncer pool for the billing database is exhausted or pgbouncer is down.

Fix: on the pgbouncer console of the database host, run SHOW POOLS. If cl_waiting keeps growing, look in the pgbouncer log for 'no more connections allowed', raise default_pool_size or find the client that holds the connections, then restart the billing service (RB-03).

X7Q-4412

Meaning: the billing service opened a database connection but the login was rejected. The password of the billing database user expired or was rotated without updating the application secret.

Fix: update the secret billing-db-password in the vault and restart the billing service (RB-03). Do not reset the database password by hand.

B2K-9001

Meaning: an invoice batch was closed twice. The second close is ignored and no data is lost.

Fix: none needed. If it repeats every night, open a ticket for team-app with the batch numbers.

Q3N-1180

Meaning: the exchange-rate feed did not answer in time; invoices in foreign currency wait in the queue.

Fix: the queue drains by itself when the feed answers again. If it lasts more than one hour, warn the finance contact.
