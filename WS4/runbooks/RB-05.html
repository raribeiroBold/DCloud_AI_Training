Clearing the cache on the API servers

When to clear the cache

Clear the response cache of the API gateway when clients receive outdated shipment data after a release, or when the cache hit ratio drops below 50% for more than ten minutes.

Procedure

  1. On one API host at a time, run: sudo api-gateway-ctl cache flush --zone shipments
  2. Check that the hit ratio climbs back above 70% within fifteen minutes.
  3. Repeat on the next API host.
