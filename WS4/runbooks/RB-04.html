Backup and snapshot of the billing database

Backup

The nightly backup is a full logical backup taken by bacula at 01:00 from db-prd-01 and db-prd-02, kept for 30 days on bkp-01 and bkp-02. It is consistent, portable to another PostgreSQL version and slow to restore (about 2 hours for the billing database). Use it to restore a single table or to move the data to another server.

Snapshot

A snapshot is a copy of the storage volume taken in seconds by the storage array, kept for 48 hours. It restores the whole volume in minutes, but only on the same array and the same PostgreSQL version. Take one before every upgrade or schema change, and never treat it as a backup: if the array fails, the snapshot is lost with it.
