Security advisory SA-2026-031: OpenSSH

The advisory

SA-2026-031 is our internal advisory for the latest OpenSSH security update from the vendors. Every host with sshd reachable from the network must get it within 7 days. It is applied by the Ansible job patch-openssh, which updates openssh-server and openssh-clients.

How to check a host

  1. On the host, look for the Ansible run in the system log: journalctl -t ansible-ansible.legacy.dnf. A line 'Invoked with name=['openssh-server', 'openssh-clients'] state=latest' means the job ran.
  2. Check that sshd was restarted after it: 'Server listening on 0.0.0.0 port 22' must come after the Ansible line.
  3. Record the host in the patch tracker.
